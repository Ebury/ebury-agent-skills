# New payee: details to add in Ebury Online

The agent never creates payees. Give the client this checklist, filled with what the document shows. Mark each missing field "needed". Ebury Online asks only for the fields that the payee's country and currency need, so some of these may not apply.

| Field | From the document |
|---|---|
| Payee type (company or individual) | |
| Account holder name (exactly as the bank holds it) | |
| Payee address and country | |
| Currency to pay in | |
| Bank name and country | |
| IBAN, or account number | |
| Sort code / routing number / BSB / other local bank code, if used | |
| SWIFT/BIC | |
| Purpose of payment, if the destination needs one | |
| Email for payment notifications (optional) | |

Before adding:

1. Confirm the bank details with the supplier through a contact you already hold, not the invoice or email that sent them.
2. Follow your internal approval process for new suppliers.
3. After it's added in Ebury Online, the agent can find it with `find_beneficiary` and pay it.

Ebury may check a new payee before it can be paid. Payments to it wait until that check is done.
